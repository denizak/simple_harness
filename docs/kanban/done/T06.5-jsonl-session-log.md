# T6.5 — JSONL session log

**Status:** done
**Commit:** `e666889`

## Scope
`JSONLSession.swift`: append-only event journal (`append` and `replace` events), opt-in via `--session-log PATH` / `HARNESS_SESSION_LOG`. One fsync'd line per event on an `O_APPEND` fd; compaction journals a `replace`; `load` skips torn lines.

## Notes
Durability only. `/save` and `/load` still own resuming. A test caught a real bug: `FileHandle.seekToEndOfFile` fixes the offset at open time, so two writers clobbered each other; raw `O_APPEND` fixed it.
